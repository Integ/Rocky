# Regions

Data is stored only in the region chosen when a project is created.

| Region       | Location    | Status              | General availability |
|--------------|-------------|---------------------|----------------------|
| us-east-1    | Virginia    | Generally available | 2024-02-01           |
| eu-west-1    | Dublin      | Generally available | 2024-05-20           |
| eu-north-1   | Stockholm   | Generally available | 2026-03-17           |
| ap-south-2   | Hyderabad   | Generally available | 2026-08-12           |
| sa-east-2    | Santiago    | Preview             | Planned for 2027     |

Preview regions have no uptime commitment and may be reset without notice.
Moving a project between regions requires an export and re-import.
