# Changelog

## 2026-08-12
- Region `ap-south-2` (Hyderabad) is generally available.
- Billing exports now include the purchase order number.

## 2026-06-01
- The Team plan rate limit was raised from 300 to 600 requests per minute.
- Deprecated the v1 `/usage` endpoint; it will be removed in 2027.

## 2026-03-17
- Region `eu-north-1` (Stockholm) moved from preview to general availability.
- SSO login pages support custom logos.

## 2025-11-03
- Initial preview of region `eu-north-1` (Stockholm).
- Team plan rate limit set to 300 requests per minute.
